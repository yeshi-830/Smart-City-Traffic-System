# 🚦 Smart City Traffic Management System

A modern web-based platform designed to improve urban transportation through centralized traffic monitoring, traffic signal management, incident tracking, and reporting.

## 📌 About the Project

My project is a **Smart City Traffic Management System** designed to improve urban transportation by providing a centralized platform for monitoring traffic conditions, managing traffic signals, tracking road incidents, and generating traffic reports.

It aims to help traffic authorities reduce congestion, improve road safety, and make data-driven transportation decisions.

## 🎯 Project Objectives

- Monitor traffic conditions across intersections.
- Manage and monitor traffic signals.
- Track and manage reported road incidents.
- Generate traffic reports and statistics.
- Support better traffic-management decisions.
- Help improve urban transportation efficiency and road safety.

## ✨ Key Features

- **Traffic Dashboard:** View important traffic statistics and system information.
- **Traffic Monitoring:** Monitor traffic conditions and intersection activity.
- **Traffic Signal Management:** View and manage traffic signal information.
- **Incident Management:** Track and monitor reported road incidents.
- **Reports and Analytics:** Review traffic statistics and generate reports.
- **CSV Export:** Export available traffic information for further analysis.
- **Responsive Interface:** Access the application on desktop and mobile devices.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Visual Studio Code (recommended)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yeshi-830/Smart-City-Traffic-System.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Smart-City-Traffic-System
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
